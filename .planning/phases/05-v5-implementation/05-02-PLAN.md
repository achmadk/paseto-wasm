  <name>Task 2: Implement V5 public signing</name>
  <files>src/v5.rs</files>
  <action>
Add V5 public signing (sign_v5_public):

1. sign_v5_public(secret_key_hex, message, footer, implicit_assertion):
   - Decode 32-byte seed from hex
   - Serialize message to JSON string
   - Get public key from seed (2592 bytes)
   - PAE encode: pk (2592) || "v5.public." || message || footer || implicit_assertion
   - ML-DSA-87 sign the PAE
   - Return: v5.public.{base64(message || signature)}[.base64(f)]

2. Helper needed:
   - get_public_key_from_seed(seed_bytes) to compute 2592-byte public key
   - This uses ml_dsa::derive_public_key() or similar
     </action>

<task type="auto">
  <name>Task 3: Implement V5 public verification</name>
  <files>src/v5.rs</files>
  <action>
Add V5 public verification (verify_v5_public):

1. verify_v5_public(public_key_hex, token, footer, implicit_assertion):
   - Verify token starts with "v5.public."
   - Decode 2592-byte public key from hex
   - Extract message || signature from base64 payload
   - Split at message_len calculation: total - 2420 (sig size)
   - PAE encode: pk (2592) || "v5.public." || message || footer || implicit_assertion
   - ML-DSA-87 verify signature
   - Return message on success

2. Error handling:
   - Invalid token header
   - Invalid public key
   - Signature verification failed
     </action>
