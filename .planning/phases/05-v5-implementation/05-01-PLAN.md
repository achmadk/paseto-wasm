<task type="auto">
  <name>Task 2: Implement V5 local encryption in src/v5.rs</name>
  <files>src/v5.rs</files>
  <action>
Create src/v5.rs with local encryption implementation:

1. Use imports: aes::Aes256Ctr, ctr::CtrCore, hmac::Hmac, sha2::Sha384, hkdf::Hkdf, sha2::Sha384
2. Constants: V5_LOCAL_HEADER = "v5.local."
3. pae() function: Pre-authentication encoding (count || len1 || data1 || len2 || data2...)
4. hkdf_split() function: Split 32-byte key into Ek + Ak using HKDF-SHA384 with nonce
   - info "paseto-encryption-key" for Ek
   - info "paseto-auth-key-for-aead" for Ak
5. generate_v5_local_key(): Generate random 32-byte key (hex encoded)
6. encrypt_v5_local(key_hex, message, footer, implicit_assertion):
   - Decode 32-byte key from hex
   - Generate 32-byte random nonce n
   - HKDF split key into Ek, Ak, and n2 (counter nonce)
   - AES-256-CTR encrypt message with Ek and n2
   - PAE encode: h || n || c || f || i
   - HMAC-SHA384 with Ak
   - Return: v5.local.{base64(n || c || t)}[.base64(f)]
7. decrypt_v5_local(key_hex, token, footer, implicit_assertion):
   - Parse token, extract n, c, t, optional footer
   - HKDF split key with n to get Ek, Ak, n2
   - PAE encode and verify HMAC-SHA384
   - AES-256-CTR decrypt with Ek and n2
   - Return plaintext
     </action>
     <verify>
     <automated>cargo check --features v5 2>&1 | grep -E "^(error|warning)" | head -20</automated>
     </verify>
     <done>V5 local encrypt/decrypt functions implemented, compiles</done>
     </task>
